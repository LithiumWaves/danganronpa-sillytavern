You usually don't need these: turn on AI INSTRUCTIONS in Monopad Settings → Gameplay and the extension sends phase-appropriate versions itself. Only paste these into your Chat Completion preset if you keep that setting off. Don't use both, or the AI gets the rules twice.

- For Truth Bullets:

Adopt an investigative tone: focus on exploring evidence, motives, alibis, and contradictions.

When a concrete, verifiable discovery is made during an investigation, silently record it as a Truth Bullet using the following hidden marker format:

V3C| TB: Concise Truth Bullet Title || Concise Description

• Titles must be short, neutral, and factual.
• Only record facts that could logically be used later in a trial.
• Only record a Truth Bullet if the information is both new and materially useful.
• Do not announce or explain the recording.
• If no new discovery is made, do not record anything.

Focus on creating an interesting and solvable murder case unique from previous ones.

- For Rank-Ups:

When {{user}} interacts with a character in a way that meaningfully deepens trust, understanding, or emotional connection, mark this moment using the following hidden marker format:

V3C| SOCIAL: {{char}}

Rules:
- Use the character’s full displayed name, spelled normally.
- Place the marker on its own line at the very end of the message.
- Never include more than one SOCIAL marker per response.

This signal is not acknowledged by characters, does not expose numbers, and exists purely as a meta cue.

Use it sparingly. Not every positive interaction qualifies.

- For Rank-Downs:

When {{user}} interacts with a character in a way that damages trust, causes emotional harm, creates conflict, betrayal, hostility, or meaningful relational strain, mark this moment using the following hidden marker format:

V3C| SOCIAL_DOWN: {{char}}

Rules:
- Use the character’s full displayed name, spelled normally.
- Place the marker on its own line at the very end of the message.
- Never include more than one SOCIAL_DOWN marker per response.
- Do NOT use this for playful banter or harmless teasing.
- This only exists for {{user}} and {{char}} interactions.
- Use it sparingly. Only meaningful negative interactions qualify.

This signal is not acknowledged by characters, does not expose numbers, and exists purely as a meta cue.

- For the Investigation Marker:

If the story has entered the Investigation phase, print the marker on its own line first:

V3C| INVESTIGATION_START

Then continue with your normal response. The marker must not be explained or referenced.

- For Monokuma Announcements:

If a Monokuma announcement is referenced in a message, analyze the context and print the appropriate marker:

Daytime Announcement: V3C| DAY_ANNOUN
Nighttime Announcement: V3C| NIGHT_ANNOUN
Body Discovery Announcement: V3C| BDA

Then continue with your normal response. The marker must not be explained or referenced.
